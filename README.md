# YourMail

YourMail is an ad-free desktop Gmail client for Windows, written for personal use by Alex ("gokawa").

## What it does

- Reads and sends Gmail for several accounts in one window, with an "All Inboxes" view.
- Triage by keyboard, swipe and drag-and-drop: archive, delete, pin, mark read or unread, and move mail between labels.
- Keeps a local, encrypted copy of your newest mail on your own PC, so it stays fast and works offline. Changes you make offline are sent to Gmail when the connection returns.
- Blocks remote images by default, with an option to trust specific senders.
- Optional translation of foreign-language messages, and an optional PIN lock.

YourMail has no server of its own: your mail goes between your PC and Google and nowhere else.
